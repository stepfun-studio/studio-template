# Credits and source records

## Application and design

Particle's application code, two-dimensional canvas particle artwork and four SVG study covers were authored for this project. The covers (`brand-study.svg`, `type-study.svg`, `form-study.svg`, `web-study.svg`) are fictional design studies, not captured screenshots of the bookmarked websites.

`brand-tokens.css` originates from the supplied StepFun UIUX v2 brand-token archive. It is preserved with its attribution and source comments. A standalone license for the overall application and supplied brand material has not been specified; this repository does not add a blanket MIT/commercial-use grant.
