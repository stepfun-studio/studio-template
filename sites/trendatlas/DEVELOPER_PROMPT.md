# 开发者复用 Prompt · 观潮 TrendAtlas

将下面的说明交给接手的开发者或编码助手，再补充本次需求即可。

---

你正在维护「观潮 TrendAtlas」——面向欧美节日装饰与家居用品外贸团队的新品研究工作台。主要任务是把社媒内容证据转成产品系列、打样任务和季度开发计划。请先读模板 README、DESIGN.md、CREDITS.md 和 source/src/，再执行本次需求。

## 本次需求

由使用者在这里填写要调整的品牌、产品范围、市场、数据接口或交互。未要求更改的内容保持现有约定；缺少真实业务信息时明确提问，不编造。

## 工程约定

- React 19 + Vite 6 + Lucide；可编辑源码位于 `source/`，根目录 `index.html` 与运行资源是构建产物。
- 在 `source/` 运行 `npm ci`、`npm run dev`、`npm test`。修改后运行 `npm run build:template` 更新上一层静态模板；不要手改压缩 JS/CSS。
- 资源必须支持根路径及 `/sites/trendatlas/` 子目录部署。图片路径用 `src/assets.js` 的 `assetUrl()`，字体与脚本本地打包。
- `preview/` 仅供 Studio 画廊，不得作为页面运行依赖。
- 优先复用现有组件：TrendCard、SocialContentCard、TrendChart、ResearchContext、ResearchFocus、PlanAction、SeasonalCalendar、Modal。

## 视觉方向

- 胡桃棕 `#50392E` 用于侧栏和主操作；暖米色 `#F6F1E8` 作为底色，奶油白 `#FFFDF9` 用于卡片。
- 酒红 `#7A3E48` / `#63333B` 用于研究重点、节日标签和收藏；鼠尾草绿 `#53664D` 用于正向信号；不要把四种颜色平均铺满页面。
- 从 CSS token 修改配色。旧 `--forest*` 是棕色 token 的兼容别名，不是需要恢复的绿色主题。
- 保留研究工作台的信息密度、清晰标签、克制动效和 Lucide 图标，不增加无业务作用的装饰图表。
- 固定侧栏的子项不能收缩裁掉内容；短窗口调整间距并允许侧栏滚动。卡片底部操作按行对齐，手机详情指标采用两列。
- 保留键盘焦点、原生表单、弹窗焦点返回及 reduced-motion；浅色区用酒红焦点框，深色区用米色焦点框。

## 数据与业务真相

- 18 条演示记录均为构造样本，固定观察基准为 2026-11-13。原始播放/曝光、点赞和时间序列都不是实际采集结果，页面、详情和导出必须保留演示标记。
- 演示与用户导入工作区隔离。未知指标保持 `null`，不能补成 0；没有历史的导入快照不能自动生成曲线。
- 原帖 URL 与平台检索入口分开；参考照片不是原帖截图或具体商品证据。原始指标按平台解释，零售上新/榜单不等于销量。
- 机会分保持可解释：社媒 ×45% + 零售 ×35% + 限制在0–100的正向增长 ×20%；该分数不是销量预测。
- 当前没有平台凭据、后台采集或真实销量接口。接入前确认来源授权、指标口径和刷新频率，并保存原帖、市场、观察日期、来源与错误状态。不得在前端嵌入密钥。
- 已确认开发至到仓约3个月，以13周计算；提前4周上架是可调整参数。日历中的开发月份与销售节日不能混淆。
- localStorage 键使用 `trendatlas:` 前缀。扩展数据结构时兼容既有收藏、导入和企划；不要为了演示清空用户数据。
- CSV 继续校验列、日期、数值、URL和重复项，未知数值留空，保留公式注入防护和旧模板兼容性。

## 验收与提交

1. 运行已有数据测试，确认构建可重复；以 HTTP 服务打开静态根目录和子目录，检查图片、字体与控制台。
2. 检查六个页面及详情/编辑/导出弹窗，至少覆盖1280×720、390×844和320×568；特别检查侧栏、表格横向滚动、卡片按钮与长文案。
3. 验证筛选重置保留观察时间、图表键盘与表格精确值、收藏和企划保存、导入失败恢复；只清理自己创建的测试数据。
4. 页面默认运行不应请求外部字体、脚本、图片或数据 API；外部调研链接仅在用户主动打开时导航。
5. 如果修改了外观或演示行为，重新录制同一版本的 `preview/cover.png` 和 `preview/video.mp4`；MP4为H.264、无音轨、faststart、5–30秒，保持真实页面比例。
6. 提交 Studio 模板时先读仓库 `docs/template-publishing.md`，只修改本模板目录及必要的清单/说明；保留其他条目与顺序。用最新 upstream main 检查冲突，不自动合并或部署。
7. PR 合并不等于上架。由环境负责人选取已合并完整 SHA 配置 `STUDIO_TEMPLATE_REF`，再验收真实画廊。

最后说明修改内容、验证命令、截图、剩余限制和涉及的数据迁移。不要把未执行的检查写成通过。
