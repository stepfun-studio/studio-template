# 可复用 Prompt

> 为「城市／街区」制作可交互的 3D 漫游路书。基于有来源的路网组织一条顺路步行路线，精选 6–9 个停靠点，提供地址、简短故事与交通建议，并明确估算信息。用 Three.js 制作可辨识的微缩地标，先验证灰模比例再细化；支持旋转缩放、点击地点聚焦、上一站／下一站和返回全景。采用当地建筑与植被提炼的配色，例如上海梧桐区的暖象牙白、树皮棕、砖红和金棕；网页与三维场景同步配色，配以宋体标题和清晰正文。桌面用阅读栏＋大地图，手机用地图＋滚动阅读区。保留资料和图片署名，提供无 WebGL 的文字回退，并交付可通过 HTTP 直接运行、支持子目录部署的本地资源包与桌面／手机实测截图。
