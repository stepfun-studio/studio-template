# 听雨便利店 · Rainy Corner

一个可以旋转、缩放和切换天气的上海街角三维微缩景观。中文虚构店铺「听雨便利店」与柔焦陆家嘴天际线形成统一的地域语境，包含店内货架、鲜食、自动门、自行车、街巷道具和雨水反射。

## 创作 Prompt

[把一场雨，装进一间便利店 · 完整创作提示词](./PROMPT.md)包含可独立复制的制作 brief、视觉与交互要求、阶段验收，以及可替换的城市、业态、天气和品牌参数，适合分享与二次创作。

## 本地运行

直接用支持 WebGL 2 的现代浏览器打开 `index.html`。也可以从仓库根目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8080/sites/rainy-corner/>。运行入口是独立 HTML，内嵌 Three.js、图标、样式、代码和程序化贴图，无需安装依赖、联网、后端或 API key。

## 交互

- 左键拖动旋转，滚轮缩放，右键拖动平移；缩放距离限制为 8–48 个场景单位。
- 右下角「雨天／晴天」按钮切换天气，支持鼠标点击、键盘 Enter 和空格；相机视角保持不变。
- 默认雨夜：雨滴、屋檐滴水、窗面滑水、地面波纹、积水和风格化实时倒影；自动门循环开合。
- 晴天：停止雨水并淡去湿地效果，切换为柔和日光和浅色远景。
- 系统启用“减少动态效果”时停止自动场景动画，天气直接切换，仍可手动查看。
- 触摸旋转与双指缩放由 OrbitControls 提供；本次移动端检查采用浏览器尺寸模拟，不宣称真实手机性能或多指手势已认证。

## 编辑与构建

可选构建环境为 Node.js 18+ 和 npm。在模板目录运行：

```sh
npm ci
npm run build
```

`npm run build` 通过 esbuild 将 `scene.js` 及其模块重新打包为 `index.html`。依赖由 `package-lock.json` 锁定；初次安装构建依赖需要网络，运行已构建入口不需要网络。修改源文件后应重新构建，不要只修改生成的 HTML。

| 文件 | 内容 |
| --- | --- |
| `PROMPT.md` | 完整创作提示词、可复用场景参数与分享说明 |
| `scene.js` / `kit.js` / `batch.js` | 场景、相机、交互、几何和文字贴图工具、静态批处理 |
| `shop.js` / `interior.js` / `props.js` / `street.js` | 店面、内景、道具与街道 |
| `ground.js` / `weather.js` | 地面、雨水、波纹、反射和自动门动画 |
| `weather-control.js` / `weather-ui.css` / `icons.js` | 天气状态、按钮样式与 Lucide 图标 |
| `skyline.js` / `backdrop.js` | 独立三维天际线渲染及柔焦背景 |
| `build.mjs` | 离线单文件打包并内嵌依赖许可 |
| `licenses/` | 完整依赖许可文本 |
| `preview/` | Studio 画廊封面与实录视频；不是运行依赖 |

## 演示边界

这是艺术化微缩景观，不是地图、真实商店或气象服务。店名、滨江路标识和食品价格均为虚构演示内容；陆家嘴建筑是可辨识的风格化剪影，不是精确测绘模型。雨水与反射不是流体模拟。

需要 WebGL 2，没有等价的非 WebGL 场景回退。性能受 GPU、浏览器和屏幕尺寸影响；小文字适合放大查看。页面不提供账号、支付、定位、实时天气、分析服务或数据持久化。
